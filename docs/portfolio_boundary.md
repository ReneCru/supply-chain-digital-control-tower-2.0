# Portfolio / Private Implementation Boundary

This repository is a deliberately reduced Portfolio Edition.

## Public evidence included

- business problem and decision lifecycle
- representative Python contracts
- deterministic OTD calculation
- simplified illustrative risk assessment
- alert and recommendation contracts
- explicit human approval gate
- outcome measurement
- synthetic data
- simplified PostgreSQL persistence schema
- representative automated tests
- CI validation

## Intentionally private

- complete scenario-intelligence implementation
- proprietary or tuned policy thresholds
- full recommendation-engine internals
- detailed remediation playbooks
- predictive-intelligence implementation
- AI-copilot internals
- complete KPI/policy catalogs
- private decision provenance/replay implementation
- production integration configuration
- non-public datasets or operational records

The objective is to make engineering ability independently reviewable without publishing the differentiated implementation needed to reconstruct the full development edition.
