# Public Code Review Scope

A reviewer can evaluate the following directly from this repository:

- correctness and readability of representative Python domain logic;
- deterministic OTD calculation;
- simplified risk classification pattern;
- separation of alert, recommendation, and human authority;
- SQL constraints for representative persistence records;
- behavioral tests for core workflow boundaries;
- automated CI execution;
- synthetic end-to-end demonstration.

The repository is not intended to expose enough implementation detail to reconstruct the complete private decision-support platform.
