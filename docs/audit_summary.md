# Pre-Public Audit Summary

- Public sample data is synthetic.
- `.env` and credential-like local files are ignored.
- `.env.example` contains placeholders only.
- The portfolio is an independent repository rather than a fork of the private development repository.
- Employer/customer/supplier affiliation is not claimed.

The public edition excludes the full scenario intelligence, tuned/private thresholds, recommendation internals, remediation playbooks, predictive intelligence, AI-copilot internals, complete policy/KPI catalogs, private provenance/replay mechanisms, production integration configuration, and non-public data.

## Claim discipline

The portfolio does not claim production deployment, autonomous procurement authority, real supplier/customer outcomes, or causation from the synthetic before/after example.
