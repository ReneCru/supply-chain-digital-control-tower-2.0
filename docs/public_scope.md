# Public Portfolio Scope

The public scope is one representative, governed supplier-delivery recovery slice. It demonstrates enough implementation to review the business-to-technology reasoning without reproducing the complete private platform.

Included: contracts, deterministic OTD, simplified risk, alert/recommendation workflow, human approval, outcome measurement, SQL schema, synthetic data, tests, CI.

Excluded: complete intelligence/policy engines, tuned thresholds, advanced playbooks, predictive and copilot internals, production integrations, private data, and full decision provenance implementation.
