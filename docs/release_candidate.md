# Release Candidate

Release candidate criteria for the Portfolio Edition:

- representative business workflow implemented;
- automated tests passing in GitHub Actions;
- synthetic demo passing in GitHub Actions;
- PostgreSQL persistence model documented in code;
- recruiter claims mapped to repository evidence;
- synthetic/public data boundary documented;
- differentiated private implementation excluded;
- source-use notice present;
- recruiter review path documented.

Remaining repository-level publication tasks are limited to GitHub metadata (description/topics) and the owner's explicit visibility change to Public.
