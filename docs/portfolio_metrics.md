# Portfolio Metrics

The public demo includes a synthetic outcome example of:

- baseline OTD: 72%
- follow-up OTD: 84%
- observed change: +12 percentage points

These values are used to demonstrate outcome-measurement mechanics. They are not presented as production results, customer results, or proof that a specific intervention caused the improvement.

Separately, the executable baseline example in `demo.py` calculates OTD from synthetic delivery observations and demonstrates the risk-to-human-approval workflow.
