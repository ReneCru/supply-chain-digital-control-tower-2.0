# 60-Second Recruiter Brief

## What is it?

Supply Chain Digital Control Tower 2.0 is a portfolio demonstration of a governed operational decision-support workflow. The public edition uses supplier On-Time Delivery (OTD) recovery to show how René Crucci translates a business problem into data contracts, deterministic analytics, automation boundaries, human approval, persistence design, tests, and measurable outcomes.

## What business problem does it solve?

A KPI dashboard can identify poor supplier performance, but teams still need a controlled path from evidence to action. This project demonstrates that path:

**Operational Data → OTD → Risk → Alert → Recommendation → Human Approval → Action → Evidence → Outcome**

## What can I verify in this repository?

- Python domain models and deterministic OTD calculation
- simplified, explicitly illustrative portfolio risk logic
- governed alert and recommendation workflow
- explicit human authorization boundary
- PostgreSQL schema with constraints and traceability-oriented records
- synthetic demonstration data
- automated pytest validation
- GitHub Actions continuous integration
- executable end-to-end synthetic demo

## Why is some implementation excluded?

This is intentionally a Portfolio Edition. The complete development edition contains additional intelligence, policies, remediation logic, provenance mechanisms, and implementation detail that are not necessary to evaluate the engineering approach and are kept private as differentiated implementation IP.

## Professional signal

The project is evidence of the working pattern:

**Business Operations → Business Problem → Data → Automation → Governed Intelligence → Measurable Outcome**

It is not presented as an autonomous procurement system or as production software.
