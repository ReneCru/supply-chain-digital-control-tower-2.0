# Governance Boundary

The Portfolio Edition separates four concepts that are often collapsed in automation projects:

1. **Evidence** — operational observations and calculated performance.
2. **Recommendation** — a proposed response to the evidence.
3. **Authority** — an accountable human decision to approve or reject the proposal.
4. **Execution / outcome** — controlled action evidence and subsequent measurement.

A recommendation does not carry authority merely because software generated it. This separation is encoded in the public workflow and tested as part of CI.
